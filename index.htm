ReGif demo

What is ReGif?
A platform-independent, low-level javascript library for building Gif files.
Why did you make it when other gif libraries exist?
Other gif libraries are not scrupulous enough when implementing the Gif spec. Sure, some of the attributes of Gif files are considered vestigial, but I think it's important to be thorough. Furthermore, in regards to other libraries: Gif.js's source code is a mess with numerous bugs and hasn't been updated in years; gifenc.js is too surface-level for my liking, and its ReadMe was confusing, and I don't like PnnQuant.
What does ReGif include?
An interface for constructing gifs (both 87a and 89a variants) at the binary level, as well as methods for:
  • Quantizing images to a limited color palette (using NeuQuant algorithm), or option for custom palette.
  • Option to create 1 bit alpha map (with option to clean stray pixels)
  • Indexing colors, with option of dithering using a variety of kernels
  • Synchronous and Asynchronous functionality (when Web Workers are available)
  • Shim that adds "image/gif" as an option for canvas.toDataURL and toBlob methods, although it will obviously be a single-frame gif.

ReGif is dependency-free, but it does require a modern javascript environment to run in (as of 2026).

Code for NeuQuant algorithms is adapted from NeuQuant.js, kernels taken from RGBQuant.js and Gif.js libraries, and LZW Encoder adapted from Gif.js library.

For more detailed explanations and usage, please consult the source code.
